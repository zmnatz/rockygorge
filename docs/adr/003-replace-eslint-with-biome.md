# Replace ESLint with Biome

The existing ESLint setup was a no-op — its flat config never loaded `next/core-web-vitals` or any plugins, so no TS/JSX files were matched and every rule reference was dead. We replaced ESLint entirely with Biome (`@biomejs/biome`, recommended preset): Biome acts as both linter and formatter (no Prettier existed before), configured fresh from `recommended` rather than migrated from the old config. We deliberately accept losing `eslint-config-next`-specific rules (react-hooks edge cases, Next-only checks) rather than dual-running two linters — Biome covers most of the gap (e.g. `useExhaustiveDependencies`). Enforcement surfaces stay as before: `npm run lint` locally and the pre-commit hook (now `biome check --staged`, replacing lint-staged); deploys still don't gate on lint.
