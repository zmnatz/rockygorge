# Where is Practice embeds the map via the legacy Google Maps endpoint

The Where is Practice page shows an embedded map of the next practice's location. The calendar item's `location` is free text, and the page must render a map without any API key or billing setup. We chose the legacy embed endpoint — `https://maps.google.com/maps?q=<location>&output=embed` — which geocodes the query when the iframe loads and needs no Google Cloud project. We rejected the official Maps Embed API (`/maps/embed/v1/place?key=...`) because it requires an API key, a billing account, and key management, and we rejected a maintained coordinates lookup table because it would add a YAML structure that must stay in sync with every practice location. Trade-off: the legacy endpoint may pin an imprecise spot for vague location text, so the page renders the map only when a location exists and falls back to plain text pointing at the team WhatsApp group otherwise.
