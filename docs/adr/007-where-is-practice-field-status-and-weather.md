# Where is Practice shows county field status via Statusfy embed and weather via Open-Meteo

The Where is Practice page warns that practice location is subject to change in inclement weather. The club's Practice Fields (Laurel and Beltsville Community Center) are maintained by Prince George's County Parks, which publishes live Field Status on a Statusfy feed with no public JSON API. We chose to render that status by embedding Statusfy's list page for the mapped field in an iframe — the integration the county builds for (60-second auto-refresh, height sync) — rather than scraping the page server-side for a custom look, since scraping HTML with no stable API would be brittle and may be bot-protected. For the weather heads-up we fetch Open-Meteo hourly forecasts client-side at coordinates stored in config, because it is keyless and CORS-friendly; we rejected keyed providers (OpenWeatherMap, WeatherAPI) for the account and secret-key management they would add. Trade-off: the page carries third-party iframe styling and depends on Statusfy availability, and the forecast is a heads-up (at least 40% precipitation probability at practice time or earlier on the same day), not an authoritative closure call — Field Status is.
